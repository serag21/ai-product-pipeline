# Little Haunts Club — Curated 42-Candidate Iteration Lab

## Why this replaces the prior correction batch

The original 15-page set had several promising compositions, but also repeated pumpkin decoration, a few malformed object relationships, black-filled window openings, awkward anatomy, and some questionable scene concepts. The nine-page revision run made several pages more technically elaborate and less charming. Only the revised grim-reaper concept seemed to improve the idea substantially, despite the grave orientation problem.

This lab preserves the stronger original cartoon look and makes three deliberately different composition candidates for each of fourteen scene slots. The existing skeleton-mermaid page remains a provisional keeper, so the final book can be assembled from the strongest alternative per slot plus that page.

## Creative rules

- Cute, expressive, rounded storybook cartoon shapes.
- Bold clean outlines and broad white coloring areas; solid black may be used sparingly where it makes visual sense.
- One central action and a small, purposeful set of supporting props.
- Background elements should explain the setting and add charm: picture frames, shelves, flowers, books, lamps, a fireplace, windows, rugs, or other relevant objects.
- Pumpkin decoration is selective, not a repeated default.
- Every object has a clear support, attachment, or held relationship.
- Each candidate stays readable as a small thumbnail and remains enjoyable to color at print size.
- Choose the strongest actual drawing—not the prompt that sounded best. A/B/C outputs are candidates, not automatic winners.

## Three-up candidate strategy

Each concept's A/B/C prompts retain the same character and story while changing composition, focal action emphasis, or prop arrangement. This supports visual comparison without changing every creative variable at once.

## Selection rubric

Score each candidate from 0–2 for each item:
1. Main concept reads instantly.
2. Character anatomy and face are coherent.
3. Physical logic and support relationships are correct.
4. Main coloring areas are broad and open.
5. Linework is clean, cute, and consistent.
6. Supporting details enrich rather than clutter.
7. The page adds variety to the collection.
8. No major defects at full resolution.

A candidate with any major anatomy/physics defect or a large accidental solid-black region is rejected even if the rest looks attractive. The generation manifest's PASS status only means basic image-integrity checks succeeded.
